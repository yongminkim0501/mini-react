# 지표 · v0.1

1. `docs/ax-plan.md` 10장과 `docs/ax-project.yml`을 읽는다. 실제 저장소·마일스톤 번호·프로젝트 시작 시각·관찰 종료 시각을 사람 기록에서 확인한다. 미정이면 임의 확정하지 않는다.
2. 저장소 루트에서 다음 읽기 전용 스크립트를 실행한다. `--until`은 체크포인트 또는 최종 보고 시점이며 미래 시각을 쓰지 않는다. 선택 인자 `--cost-total`에는 사람이 확인한 동일 기간 총액만 넣고 통화도 보고한다.

   ```sh
   python3 scripts/ax/metrics.py --repo OWNER/REPO --milestone NUMBER \
     --since START_UTC --until REPORT_UTC
   ```

3. 출력의 개별 이슈·시간·누락 사유를 확인하고 M1~M8 표로 옮긴다. M3 중앙값에는 완료 건만 포함하고, 열린 건은 별도 경과 시간으로 적는다. 스크립트는 보고 시점의 상태를 읽으므로 과거 시점을 소급 지정하지 않는다. GitHub 오류나 일부 수집 실패를 0으로 대체하지 않는다.
4. M1 최초 본문은 현재 본문으로 대체하지 않는다. 최초 등록 기록을 확보하지 못하면 N/A로 남긴다. M6 재오픈 수는 부분 수치이며 같은 문제의 재등록 여부는 사람이 이슈 링크·원인을 검토해야 한다. M7은 동기화의 사례 목록을 확인하고 건수와 한 줄 메모로 적는다. 미기록을 0건으로 단정하지 않는다.
5. M8은 총액/M2의 근사치임을 표시한다. API 과금 귀속 데이터가 있다면 이슈별 비용을 별도로 제시한다. 분모 0은 N/A, 결측은 N/A, 비율은 분자·분모를 함께 적는다. M5는 자동 종료 미사용으로 N/A다.
6. 열린 PR의 실제 영역과 관련 이슈의 예상 영역을 비교해 추가 영역 비율(분자/검토한 PR 수)을 참고 수치로 제시한다. 링크가 없거나 삭제된 라벨은 결측으로 분리한다. 작은 표본의 변화로 성과나 인과를 주장하지 않는다.

이관 전에 수집한다. 마일스톤에서 옮겨진 이슈는 현재 목록에서 빠지므로 종료 보고 시 원래 이슈 목록과 이관 기록으로 대조한다. 스크립트 결과는 집계 산출물이며 GitHub 이슈 사본을 만들지 않는다.
